Factory Inventory Management

A two-process, demo full-stack application — Vue 3 single-page client and a FastAPI service serving in-memory data from JSON fixtures. Built as a Claude Code workshop project.

Frontend · localhost:3000
Backend · localhost:8001
Persistence · None (JSON in memory)
Auth · None (demo only)

Tech Stack

Frontend

Vue 3 SPA

Composition API throughout. Vite dev server on port 3000. SPA routing via vue-router (history mode). HTTP via axios. No state library — shared state lives in composables.

Vue 3.4 Vite 5.2 vue-router 4.3 axios 1.6

Backend

FastAPI Service

Single-file app (~310 lines) on uvicorn, port 8001. Pydantic models validate all responses. JSON fixtures load into module-level globals at startup; mutations don't persist. CORS is wide-open for local dev.

Python 3.11+ FastAPI ≥0.110 Pydantic 2.5 uvicorn 0.24 uv

System Architecture

Request Lifecycle

Every screen in the app follows the same flow. The four global filters (warehouse, category, status, time period) flow as query params on every request.

1
User changes a filter

FilterBar updates refs inside useFilters composable. Views watch these refs and re-fetch.

2
View calls the API client

client/src/api.js serializes filters into URLSearchParams, skipping any value equal to 'all'.

3
FastAPI receives the request

Route handler accepts warehouse, category, status, month as Optional[str] query params.

4
In-memory filtering

apply_filters() chains warehouse → category → status. filter_by_month() expands quarter codes (Q1-2025 → three months) via QUARTER_MAP.

5
Pydantic validates the response

Each route declares a response_model — dicts are coerced into typed models; mismatches raise at the boundary.

6
Vue renders via computed

Raw arrays land in refs (allOrders, inventoryItems). Derived values — totals, groupings, chart data — live in computed() so they recache only when inputs change.

Patterns Worth Knowing

Filters are one shared composable useFilters holds refs at module scope, so every view sees the same selection without prop drilling or a store.
Raw refs + derived computed Fetched arrays live in plain refs. Totals, groupings, and chart series are computed properties — cached and reactive.
Quarters map to month lists server-side Client sends Q1-2025; QUARTER_MAP expands it to ['2025-01', '2025-02', '2025-03'] for substring matching.
Inventory ignores time No order_date on inventory items — month and status filters are accepted but no-op there.
No persistence layer All data lives in module-level globals populated from JSON at boot. Restart = full reset. POST endpoints (tasks, purchase orders) exist but mutations evaporate.
Single-file backend Routes, models, and helpers all in server/main.py. Intentional — easier to read end-to-end during the workshop.
